# Project Story

I approached this project as a small real-world analytics assignment rather than simply making a collection of charts.

I started with the Olist e-commerce data and used PostgreSQL to organize the data, validate important fields and create the analysis-ready views needed for reporting.

After that, I connected the required data to Power BI. I created a dedicated date table, built DAX measures for the main KPIs and designed the report around four clear analytical questions: overall performance, sales, customer behavior and delivery operations.

The final Key Business Insights page brings the analysis together. It focuses on what the numbers mean for the business and what could be done next.

## The overall flow

**Raw Data → SQL → Validation → Views → Power BI → Data Model → DAX → Dashboard → Insights → Recommendations**

## Interview-ready explanation

> I worked on an e-commerce analytics project using PostgreSQL, SQL and Power BI. I started by loading the Olist data into PostgreSQL and used SQL to validate the data, join the required tables and prepare analysis-ready views. I then connected the data to Power BI, created a date dimension and DAX measures, and built dashboards for overall performance, sales, customer RFM and delivery operations. The analysis showed a very low repeat customer rate, a significant At-Risk customer segment, strong overall on-time delivery and a concentration of late deliveries in São Paulo. I finished the project by turning these findings into business recommendations.
